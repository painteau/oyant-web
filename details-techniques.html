Détails techniques

Comment Oyant fonctionne, comment l'installer sous Linux, et où il range vos données. Pour simplement vous en servir, la page d'accueil suffit.

Tout se passe sur votre ordinateur

La reconnaissance vocale repose sur whisper.cpp et les modèles Whisper d'OpenAI, exécutés sur votre machine. Le logiciel est écrit en Rust, avec une interface Tauri, légère et rapide à démarrer.

Transcrire ne demande aucune connexion. Oyant ne se connecte à Internet que lorsque vous le lui demandez, pour télécharger un modèle de reconnaissance ou un moteur plus rapide, et chaque fichier reçu est vérifié par son empreinte avant d'être utilisé.

Trois modèles, selon vos priorités

Vous choisissez dans le logiciel, et vous pouvez changer à tout moment. Durées mesurées sur un processeur courant, pour une dictée d'une trentaine de secondes.

ModèlePoidsDuréeIdéal pour
Small488 Moenviron 7 sLa dictée de tous les jours. C'est le choix proposé au départ.

Plus rapide avec une carte graphique

Oyant fonctionne sur n'importe quel ordinateur dès l'installation, sans rien télécharger d'autre. Si votre machine a une carte graphique, un moteur accéléré la met à contribution.

MoteurPoidsMatérielVitesse
Processeurinclustous les ordinateursréférence
Vulkan21 Mocartes AMD, Intel et NVIDIAjusqu'à 3,4 fois plus rapide
CUDAplus de 600 Mocartes NVIDIAenviron 15 % de plus que Vulkan

Oyant ne vous propose que ce que votre ordinateur sait faire tourner : le moteur CUDA n'apparaît que si une carte NVIDIA est détectée. Dans presque tous les cas, Vulkan offre le meilleur rapport entre vitesse et poids.

Le téléphone comme micro

Avec l'application iPhone, bientôt disponible, votre téléphone sert de micro sans fil : il capte votre voix et l'envoie à votre ordinateur, qui la transcrit et écrit le texte là où se trouve votre curseur.

  • Directement sur votre réseau local. Le téléphone trouve l'ordinateur sur votre wifi, sans adresse à taper ni compte à créer, et rien ne transite par Internet.
  • Une connexion chiffrée et authentifiée. À la première connexion, les deux appareils affichent le même code à quatre chiffres. Ensuite, chaque appareil prouve son identité par une clé qui ne quitte jamais le téléphone.
  • Vous gardez la main. La fonction est désactivée tant que vous ne l'activez pas dans les réglages, et vous retirez un téléphone autorisé depuis la liste des appareils.

Installer sous Debian ou Ubuntu

Oyant est publié sur le dépôt apt de l'association. Ajoutez-le une fois : les versions suivantes arrivent avec les mises à jour habituelles de votre système.

curl -fsSL https://apt.breizhzion.com/KEY.gpg \
  | sudo gpg --dearmor -o /usr/share/keyrings/breizhzion.gpg

echo "deb [signed-by=/usr/share/keyrings/breizhzion.gpg] \
https://apt.breizhzion.com stable main" \
  | sudo tee /etc/apt/sources.list.d/breizhzion.list

sudo apt update && sudo apt install oyant

Les dépendances s'installent avec le paquet. Vous préférez un téléchargement direct ? Le paquet seul est disponible ici.

Installer sous Arch

Dépôt pacman de l'association, paquets signés.

printf '\n[breizhzion]\nSigLevel = Required DatabaseRequired\nServer = https://pacman.breizhzion.com/$arch\n' \
  | sudo tee -a /etc/pacman.conf

curl -fsSL https://pacman.breizhzion.com/KEY.gpg | sudo pacman-key --add -
sudo pacman-key --lsign-key apt@breizhzion.com

sudo pacman -Syu oyant-bin

Utilisez bien -Syu, comme le recommande Arch, pour mettre le système à jour en même temps.

Systèmes pris en charge

  • Windows 10 et 11, en 64 bits.
  • Linux, sur les sessions X11. La prise en charge des bureaux Wayland est en cours.
  • macOS : en préparation.

Où sont vos données

Vos réglages, les modèles téléchargés et, si vous l'activez, l'historique de vos dictées sont rangés dans votre profil utilisateur, et nulle part ailleurs :

SystèmeEmplacement
Windows%LOCALAPPDATA%\org.breizhzion.oyant.desktop
Linux~/.local/share/org.breizhzion.oyant.desktop

L'historique est désactivé par défaut : rien de ce que vous dictez n'est écrit sur le disque tant que vous ne l'avez pas choisi. Le remettre à zéro efface ce qui avait été gardé, et supprimer ce dossier efface tout définitivement.
